# 项目工作空间模板 · 使用说明

> 这个文件夹是**每个新项目的起点**。复制整个文件夹、改成你的项目名，就能开始一个新文案项目。

---

## 三步用法

```
第1步：复制整个「项目工作空间模板」文件夹
第2步：改名为你的项目名（例：富豪离婚避税）
第3步：打开对话，把「启动提示词.md」内容发给AI，告诉它工作目录
```

---

## 目录结构说明

| 目录 | 放什么 | 对应流程 |
|------|--------|----------|
| `参考文案/` | 用户给的参考文案（视频转写/文章原文，可多篇） | S0接收 |
| `分析/` | AI生成的分析卡（保存+对话双输出） | S1分析参考文案 |
| `资料收集/` | 资料卡、素材评分表、覆盖情况 | S2资料收集 |
| `主题选项/` | 5个主题选项 | S3主题选项 |
| `大纲/` | 确认后的大纲 | S4写大纲 |
| `文章生成/` | 最终正文 | S5写文章 |
| `封面标题/` | 封面+标题 | S6封面标题 |

每个目录里都有 README.md 说明具体放什么，也可以直接删掉这些说明文件。

---

## 铁律（写死）

1. **每步完成必须停下等确认**，AI不能自动连做下一步
2. **所有产出双输出，顺序写死**：S1分析卡 / S4大纲 / S5正文 / S6封面标题
   → ①先在对话输出完整内容 ②再保存到对应目录，一个都不能少
3. **大纲先行**：即使用户说"开始写文章"，也必须先出大纲等确认
4. **启动先确认写作模式**：精炼模式（默认推荐）/ 创新模式，没说模式禁止开跑；**精炼模式永远跳过S3**
