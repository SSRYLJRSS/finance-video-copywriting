# 资料收集

放**S2资料收集**的产出（按子目录分类）：

```
资料收集/
├── 事件与时间线/    # 事件发生过程、关键节点、官方通报
├── 数据与报告/      # 统计局/财报/行业报告的核心数据
├── 舆论与案例/      # 网友高赞评论、同类案例
├── 行业与机制/      # 机制解释、行业背景
├── 资料卡.md        # 每条素材的资料卡（含来源URL）
├── 素材评分表.md    # S/A/B/C/D评分
├── 覆盖情况.md      # 搜索清单各问题覆盖情况
└── README.md
```

> 子目录也可以直接放文件（如 `事件与时间线/通报原文.txt`）
