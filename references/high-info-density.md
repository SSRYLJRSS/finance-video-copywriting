# 高信息熵与场景链规则

> 适用：人物案例、评论文案、社会现象类文案。解决"用概括替代真实经历"和"为转场硬凑句子"的问题。

## 核心原则

先让观众看见一个人怎样被规则一步步卡住，再解释这套规则叫什么。

### 固定顺序（事件链）
```
承诺/期待 → 第一次异常 → 尝试解决 → 规则反杀 → 直接代价 → 机制解释 → 宏观回扣
```

**示例**：`28元招聘 → 入职23元 → 找中介被拉黑 → 离职按16元算 → 12小时倒班与休息被吞 → 临时工成本机制 → 全球第一与无社保的反差`

**关键**：在事件链未走完前，不要过早写"资本压榨、行业黑暗、工人成了耗材"。这些话只能承担解释或收束，不能代替经历。

## 素材不只按分数筛选

素材评分表必须增加"事件链功能"列：`钩子`、`入场场景`、`异常`、`反转`、`规则`、`代价`、`机制`、`收束`。

低共鸣素材只要承担流程功能，也要保留。体能测试、排队吃饭、请假医院单、罚师傅工资等，未必是最强钩子，却是让文章真实、连续的关键细节。

## 每段必须有信息增量

每段至少新增一项，优先新增两项：

| 类型 | 说明 | 示例 |
|------|------|------|
| **数字** | 金额、时长、数量、比例 | 371万人、被罚1200、跌了6.53% |
| **动作** | 具体行为 | 半夜铲字、拉黑微信、排队打饭 |
| **规则** | 制度/条款 | 离职提前申请、转正门槛、处罚方式 |
| **关系** | 人际互动 | 中介甩锅、工厂与中介踢皮球、师傅替新人挨罚 |
| **后果** | 直接损失 | 回不了家、睡不着、腿发抖、被扣钱 |

**检验方法**：把事件主体换成任何行业后，这段依然成立=太抽象=补回只属于该事件的动作、规则或数字。

**正反对比**：
- ❌ "加班很累"（废话，换任何行业都成立）
- ✅ "每天干14小时，底薪两千三，驴都没这么拉磨的"
- ❌ "加班更是地狱模式"（高度概括，产生距离感）
- ✅ "排队打饭就要10多分钟，来回路程再10多分钟"

## 过渡由问题触发

每段结尾留下观众自然会问的问题，下一段只回答它。

```
工资被扣 → 那为什么不离职？
想离职 → 直接跑会怎样？
工作12小时 → 12小时具体怎么熬？
临时工很多 → 企业为什么爱用？
```

**禁止的过渡方式**：
- ❌ "更扎心的是""最魔幻的是"等路标词硬拐
- ❌ 对仗式金句硬拐话题
- ❌ 无铺垫的生硬转折
- ❌ "那问题来了，我给你拆三颗炸弹"——太客气，像老师讲课
- ✅ "你觉得大佬在吓唬人？现实数据就摆在这里"——有对抗感

## 逻辑链铁律

写大纲时，不要只想"这段讲什么"，要想"观众看完这段会问什么"——下一段必须回答那个问题。

不是"列清单"式并列（段1讲A、段2讲B），而是"问-答"式递进：
```
大佬为什么跑？→ 数据证明不是吓唬人 → 到底是什么雷？→ 金丝雀在叫 → 跟你有什么关系？
```

### 开头合并原则
同一维度信息（如"大佬跑路"+"专家预警"属于同一"恐惧信号"）合并成一段。拆开=观众觉得"怎么还没讲完"。

### 历史规律独立成段
当有"历史规律"类素材（如"每次危机韩国都先崩"），要独立成段，不要嵌在其他段落里当附件。独立成段+用比喻强化（"烟雾报警器"），观众秒懂。

## 金句只在情绪临界点出现

顺序必须是：`具体细节 → 情绪累积 → 一句自然反应`

- ✅ "剩余的工资被狗吃了吗？"
- ✅ "干你妹啊，离职吧"
- ❌ "财报好看了，工人的命却贱了"
- ❌ "资本家的算盘珠子，都快崩到工人脸上了"

一句话脱离前文仍像"标准金句"，大概率是硬凹；必须依赖前文具体事实才有力量，才该留。

## 宏观数据只做夹子

- **开头**：用最强反差定调（3.5万→7970亿）
- **中段**：以人物、规则、动作和直接代价为主
- **结尾**：回扣开头的具体钱、时间、保障或尊严矛盾

事件链是文章主体时，事实叙事可以超过全文三分之一；限制的是重复结论，不是具体经历。

## 机制解释（不要独立成段）

不要写长篇科普。要把机制揉进故事里。

**公式**：`具体现象 + "说白了，这就是……" + 利益分配解释`

- ❌ "DTC（Direct-to-Consumer）模式是指品牌直接面向消费者销售……"（百科式）
- ✅ "说白了，就是不想让直播间互相背刺，自己把价格控死"

连续三句以上解释性文字必须插入案例、反问或总结。

## 快速终检

- [ ] 钩子后是否连续推进同一事件的2-4个异常？
- [ ] 是否先讲完人物如何被坑，再讲行业机制？
- [ ] 每段是否有新的数字、动作、规则、关系或后果？
- [ ] 是否保留了低流量但能证明流程真实的细节？
- [ ] 每次转场是否回答上一段自然留下的问题？
- [ ] 每句吐槽是否由前文事实推出来？
- [ ] 宏观判断是否只在定调或收束处出现？
