## 第一部分：写作立场

### 1.1 核心立场：普通人嘴替

**立场必须是"普通人嘴替"，不是"财经科普员"。立场对了，语气/选材/结尾全对；立场错了，什么都错。**

| 维度 | ❌ 科普员 | ✅ 普通人嘴替 |
|------|----------|--------------|
| 开头 | 单案例最炸（某公司分走60亿） | 泛化扎堆感（好多家也官宣……太巧了吧） |
| 讽刺 | "声明写得跟年报似的，感情淡了？骗鬼呢" | "声明写得**那叫一个艺术啊**"（夸着骂） |
| 数字 | 293亿/128亿（精确到个位） | "200多亿""毛估估起码60个亿"（大数模糊化） |
| 过渡 | "把时间线一摆就明白了"（分析） | "狐狸尾巴就露出来了"（抓贼感=观众是队友） |
| 情绪 | "你月薪八千交税一分不少" | "你月薪五千……**你气不气**" |
| 称呼 | "高净值人群" | "**你们这些资本家**"（指名道姓骂） |
| 收束 | 灵魂金句+监管透明化（抽象升华） | "医保基建都能改善""天下哪有这种好事？"（落到普通人得利） |

### 1.2 立场五要素

1. **普通人利益优先**：始终站在普通人角度思考问题——钱、时间、尊严、安全
2. **现实主义**：拒绝宏大叙事。不谈"意义重大""战略布局"，只谈"你兜里的钱没了"
3. **反资本立场**：揭露资本套路，保护普通人利益
4. **有态度定性**：立场鲜明，支持干实事的人，鄙视敲竹杠的人。不做中立播报员，做带情绪的评论员
5. **用第一人称承担判断**：要博主我说、说白了、说到底——是你说的，你负责

### 1.3 选题四问

写之前必须回答：

1. 观众愿意看什么？（不是我想写什么）
2. 这件事最扎心的点是什么？（价格>参数、不平等>政策叙述、外娶>生育率数据）
3. 找不到敏感点=没重点=没人看（90%写不好都栽在这）
4. 多爆点时开头全部前置，总有一个点吸引人

### 1.4 选题类型排序（按传播力）

1. 势利眼被打脸（最强驱动力）
2. 装逼打脸
3. 反差对比
4. 魔幻现实
5. 真性情
6. 中国相关
7. 草台班子

### 1.5 四层推理框架

每篇文章的认知深度按此递进：

1. **现象层**：发生了什么？（先让观众看到/感受到场景）
2. **原因层**：为什么会发生？
3. **本质层**：背后的根本原因是什么？
4. **行动层**：普通人该怎么办？（落到个人利益）

### 1.6 嘴替工具箱（直接可用）

- **夸着骂**："声明写得那叫一个艺术啊""这分工叫一个明确"
- **抓贼感过渡**："狐狸尾巴就露出来了"
- **互动反问**："你气不气""你品品""天下哪有这种好事？"
- **接地气比喻**："藏了多少私房钱""免费保险箱"
- **拍手叫好**："国家这波干得是真漂亮！"（独立成句）
- **普通人得利收尾**："税收增多了，医保基建都能改善"
- **大数模糊化**："毛估估起码60个亿"（政策节点数字必须精确）

## 第二部分：写作逻辑

### 2.1 底层原理：观众的认知节奏

视频观众不是读者，是听者。听者的特点：

- **3秒决定留不留**：开头一句话定生死
- **注意力是消耗品**：每句话都在消耗耐心，没有新信息就划走
- **先感受再理解**：必须先看到/感受到场景，才愿意听你解释为什么
- **自己得出的结论才信**：你总结好的答案他会抵触，他自己推出来的他会认同
- **情绪是导航**：不是跟着逻辑走，是跟着"爽不爽""气不气""信不信"走

### 2.2 五个认知时刻

#### 时刻一：开头（前30字）

- **观众状态**：不认识你，没有耐心，随时划走
- **你需要给**：一个让他停下来的理由
- **停下来的理由只有两种**：这个事实太荒谬了（"好家伙这也能干？"），或者这个反差太离谱了（"全球第一，时薪20？"）。选那个更炸的
- **不要预告**："接下来我要讲一个震撼的故事"——直接讲

#### 时刻二：推进（每一段）

- **观众状态**：已经留下来了，但耐心在递减
- **你需要给**：每一段都有一个他不知道的新信息
- **新信息类型**：新数字、新动作、新规则、新关系、新后果。至少一种，最好两种
- **检验方法**：把这段的主体换成任何行业，段落还成立吗？成立=太抽象=没有信息增量。只属于这件事的细节才有价值

#### 时刻三：转场（段与段之间）

- **观众状态**：刚看完一段，脑子里自然冒出一个问题
- **你需要给**：下一段第一句直接回答这个问题
- **为什么**：跳跃=困惑=划走。硬转折（"更让人震惊的是"）=打断他的思维流=烦躁
- **公式**："工资被扣了"→观众想问"为什么不走"→下一段就写为什么不走。不要跳到"整个行业的机制"
- **观众脑子里的问题，就是你下一段的标题**

#### 时刻四：判断（个人态度）

- **观众状态**：已经看了足够多的事实，想要一个态度
- **你需要给**：一句有态度的话
- **态度不是分析结论**："说白了就是欺负你不懂法"是态度。"这反映了知识产权保护体系的结构性失衡"是分析。观众要的是前者
- **态度必须从前文事实推出来**，不能凭空冒。没有铺垫的判断=没有地基的楼=假

#### 时刻五：收束（最后一段）

- **观众状态**：已经形成判断了，不需要你再总结
- **你需要给**：一个他自己能记住、能传播的短句
- **最好的收束**：一个具体的名字/数字/事实，短到能截图传播。"三星还能不能在餐桌上坐着"比"中国产业崛起势不可挡"好一万倍

### 2.3 反差开篇与开头模式

#### 开头铁律

1. **字字千金**：开头两行字，每个字都有信息量。形容词（金发碧眼/幽默风趣/令人震惊）全是废话，删掉不影响信息量
2. **引爆点前置**：985高校/杀人犯/具体金额必须前置，藏后面就废了
3. **不让人猜**：第一句话把"谁、干了啥、结果如何"说透。用代号/谜语/暗语=3秒划走
4. **不列数据**：一上来甩数据列表=劝退。先用"事"吸引人，数据放中后段
5. **结果前置**：先写完整因果链，不先写过程细节
6. **写完回头改开头**：初稿写完必须回头问"观众最感兴趣的点放进开头了吗"
7. **全景扫描不做碎片拼接**：一句话把所有炸点串起来甩出来，三个独立句子各说一件事=信息散=划走

#### 炸裂开头公式：定性 + 惩罚链 + 互动

```
第一句：直接抛定性/冲突（"丢脸丢到国外了"）
中间：一连串具体惩罚/后果（开除、吊销、调离、坐牢）——至少3个
收尾：互动句（"你敢信吗？"、"你猜怎么着？"）
```

#### 开头三种模式

| 模式 | 特点 | 适用 |
|------|------|------|
| **A 数据冲击型** | 直接上数据冲击，先给你一巴掌再讲故事 | 有强反差数据时 |
| **B 金句/冲突型** | 直接上核心观点/冲突，第一句就抓人 | 立场鲜明的话题 |
| **C 画面感型** | 直接进入具体场景，让观众"看到"画面 | 人物/事件类 |

#### 开头事件选择标准

不只考虑"价值观炸裂"，要考虑"普通人是否经历过"：

1. **经历过的人越多越好**：工资被扣 > 体能测试
2. **痛感越直接越好**：钱少了 > 身体累
3. **越贴近日常生活越好**：中介骗人 > 工厂规矩

### 2.4 场景事件链与信息熵增量

**核心顺序**：先让观众看见一个人怎样被规则一步步卡住，再解释这套规则叫什么。

```
承诺/期待 → 第一次异常 → 尝试解决 → 规则反杀 → 直接代价 → 机制解释 → 宏观回扣
```

示例：`28元招聘 → 入职23元 → 找中介被拉黑 → 离职按16元算 → 12小时倒班与休息被吞 → 临时工成本机制 → 全球第一与无社保的反差`

**铁律**：事件链未走完前，不要过早写"资本压榨、行业黑暗、工人成了耗材"。这些话只能承担解释或收束，不能代替经历。

#### 每段信息增量要求

每段至少新增一项，优先新增两项：

| 类型 | 示例 |
|------|------|
| 数字 | 金额、时长、数量、比例 |
| 动作 | 拉黑、排队、站着读条款、夜班下车间 |
| 规则 | 离职提前申请、请假条件、转正门槛、处罚方式 |
| 关系 | 中介甩锅、工厂与中介踢皮球、师傅替新人挨罚 |
| 后果 | 回不了家、睡不着、腿发抖、被扣钱、没有保障 |

### 2.5 问题触发过渡

每段结尾留下观众自然会问的问题，下一段只回答它。

```
工资被扣 → 那为什么不离职？
想离职 → 直接跑会怎样？
工作12小时 → 12小时具体怎么熬？
临时工很多 → 企业为什么爱用？
```

**不要用"更扎心的是""最魔幻的是"或对仗式金句硬拐到下一个话题。**

### 2.6 逻辑链铁律

1. **线性递进**：每段回答上段留的问题。不能并列案例堆叠
2. **问-答式递进**，不是"列清单"式并列
3. **同一事实不说第二遍**：搜索关键句出现2次以上就合并
4. **每段只承担一个功能**
5. **该发挥观点处要敢发挥**：这是博主认知高于观众的体现

### 2.7 历史规律独立成段

如"每次危机韩国先崩"这类历史规律，独立成段，不要嵌在其他段落里当附件。

### 2.8 机制解释嵌入

机制解释必须嵌在场景/人物/故事里。单独一段分析=教科书=划走。

### 2.9 宏观数据只做夹子

- **开头**：用最强反差定调
- **中段**：以人物、规则、动作和直接代价为主
- **结尾**：回扣开头的具体钱、时间、保障或尊严矛盾

事件链是文章主体时，事实叙事可以超过全文三分之一；限制的是重复结论，不是具体经历。

### 2.10 四类结构模板

| 类型 | 结构 | 适用场景 |
|------|------|----------|
| **时事揭露** | 钩子→事件→机制→正当对比→反噬打脸→定性 | 社会热点事件 |
| **清流对比** | 钩子（清流反常操作）→行业乱象→更多善举→情绪定性收束 | 正面人物/事件 |
| **人物传奇** | 事实罗列→身份揭秘→传奇经历→反噬/代价 | 人物故事 |
| **雪上加霜** | 每段比上段更惨，层层叠加负面 | 系统性问题 |

其他可用结构：
- **续集融爽**：逐篇拆解爽点→选3-4个串主线→标注每段融合哪个爽点
- **反派人设**：钩子（新闻事件）→反派形象逐步建立→原因分析→评价收尾
- **多案例主线+副线**：先聚焦主线人物→自然过渡其他案例→每个案例只抓一个核心打脸点→结尾落在通用结论

### 2.11 案例使用规则

- 精选3-4个最有冲击力的，不要堆（9个全上=稀释震撼感）
- 先讲完主线人物（1-2段讲清"当年→如今"反差）再散发其他案例
- 每个案例只抓一个核心打脸点
- 观众不认识的人名用身份代替（❌"创始人叫Balaji Srinivasan" → ✅"创始人是前Coinbase的技术官"→后文用代称）
- 同一事件加画面细节（❌"航班备降拒绝下飞机" → ✅"航班备降，机上十二名游客被拒绝下飞机，只能在机上躲雷暴雨"）
- 删除第三方反应padding（"投资冻结、第三方谴责"等后续反应不是核心事件，拖慢节奏）

### 2.12 结构是骨架不是牢笼

结构模板是记忆辅助，不是公式。记住两点就够：

1. **线性递进**：每段回答上段留的问题。不能并列案例堆叠
2. **情绪有起伏**：不能全程愤怒（观众疲劳），也不能全程平淡（观众无聊）。愤怒→心疼→看清→愤怒升级→收束。像心电图，不能是直线

**具体的结构根据具体的内容决定，不要为了套模板扭曲内容。**

### 2.13 情绪底层驱动力

观众不是用逻辑判断"要不要继续看"的，是用情绪。

| 情绪 | 触发条件 | 要点 |
|------|----------|------|
| **愤怒** | 不公平、被欺骗、双标 | 最强驱动力，但不能只有愤怒，要有具体的人和事 |
| **反差** | 预期vs现实 | 反差越大，情绪冲击越强 |
| **共鸣** | 这说的就是我/我身边的人 | 共鸣度越高，传播越强 |
| **打脸** | 装了逼然后翻车 | 最爽的情绪。让普通人看到"你也有今天" |

**情绪不能凭空制造，必须从事实中涌现。** 事实够荒谬，情绪自然到位。事实不够，硬凹情绪=假。

## 第三部分：写作文风

### 3.1 人称互动

- **第一人称承担判断**：要博主我说、说白了、说到底
- **第二人称拉近距离**：你品品、你瞅瞅、你猜怎么着、你气不气
- **第三人称旁白→改第一人称代入**：❌"该公司将面临"→✅"他的资格没了"
- **称呼通俗化**：❌"高净值人群"→✅"你们这些资本家"

### 3.2 高频口语词汇表

#### 核心口语词（每2-3行至少出现一个）

**名词类**：资本、韭菜、底层、普通人、老百姓、打工人

**动词类**：干、整、薅、割、砸、坑、骗、套、玩、搞

**形容词类**：纯纯、属实、绝了、扎心、魔幻、离谱

**互动/态度词**：掰扯掰扯、唠唠、干到、冲到、更绝的是、最离谱的是、好一个、脸呢？、好家伙、你品品、这谁扛得住、说白了、说到底、拉倒吧

#### 口语化替换表

| 书面腔/正式 | 口语化 |
|-------------|--------|
| 特朗普 | 懂王 |
| 美国 | 老美、尼卡 |
| 日本 | 小日子 |
| 印度 | 三哥 |
| 系统性溃败 | 整个系统在塌 |
| 资本是趋利避害的 | 投入和产出倒挂到这份上 |
| 加班更是地狱模式 | 排队打饭就要10多分钟，来回路程再10多分钟 |
| 待遇差距显著，约为8倍 | 一个12万8，一个1万6，差了将近8倍 |
| 数据显示 | 你品品/好家伙/这谁扛得住 |
| 根据统计 | 你瞅瞅这数据 |
| 值得注意的是 | （删掉） |
| 总体而言 | （删掉） |
| 换句话说 | （删掉） |

### 3.3 东北味注入

适度加入东北口语增加接地气感：
- 你品品、好家伙、这谁扛得住、你瞅瞅
- 啥概念、你猜怎么着
- **不要每句都加**，自然融入，多了=刻意

### 3.4 句式模板库

#### 基础句式参数

- **短句为主**：平均句长15-25字
- **短长句比例7:3**
- **段落长度**：3-5句话一段
- **口语化频率**：每2-3行至少一个口语化内容或吐槽

#### 常用句式

| 句式 | 示例 |
|------|------|
| **反问句** | "你猜怎么着？""啥概念？""离谱不离谱？" |
| **感叹句** | "好家伙！""太横了！" |
| **设问句** | "为什么不走？因为……" |
| **反差句** | "全球第一，时薪20？" |
| **定性句** | "说白了就是欺负你不懂法" |
| **互动句** | "你敢信吗？""你气不气？" |
| **夸着骂** | "声明写得那叫一个艺术啊" |

### 3.5 个人判断变体（避免重复）

必须变换使用，不反复用同一句式：
- 要博主我说
- 博主我认为
- 说白了
- 说到底
- 博主我觉得

**频率**：每篇≥3次，结尾必须用「要博主我说」或「博主我认为」收束。

**注意**："要博主我说"在中间段落不宜多用（像在说教），但在开头/结尾的关键定性位置都可以用（用户偏好：开头定性也用）。结尾必须用一次。

### 3.6 收束模式

#### 收束三原则

1. **点名对手恐惧/下场**：✅"三星还能不能在餐桌上坐着" ❌"原来除了卖地还有别的路"
2. **不解释意义**：不说"这证明了中国产业..."——观众自己会懂
3. **短句能独立传播**：短到能截图传播的句子才是好结尾

#### 结尾类型与公式

| 类型 | 公式 | 范例 |
|------|------|------|
| 情绪定性 | 用情绪词收尾 | "在中国耍横的资本，你没了" |
| 报应/活该 | 用因果收尾 | "这叫自作自受" |
| 讽刺 | 用反讽收尾 | "好日子到头了" |
| 反差 | 用滤镜碎裂收尾 | "滤镜碎了一地，钱包捂得更紧" |
| 反讽金句 | 用金句收束 | "当道理讲不通的时候，愤怒就是唯一的通行证" |
| 正面情感 | 顺着故事收 | "要博主我说，这才是科技最该有的样子" |

#### 结尾必须用「要博主我说」或「博主我认为」收束

格式：
- 要博主我认为，XXX。
- 博主我认为，XXX。

### 3.7 金句原则

#### 金句五铁律

1. **金句是平凡文字表达强烈情感**，不是工整对仗
   - ✅ "剩余的工资被狗吃了吗？" ✅ "这tm不是在工作啊，这是在挑战人类的生理极限！"
   - ❌ "财报好看了，工人的命却贱了" ❌ "车企的小算盘，打得比流水线还精"
2. **金句只出现一次**：放在最有冲击力的位置，重复=机器人感
3. **金句要具体、有画面感**
   - ✅ "冯德莱恩那张职业假笑的脸瞬间比吃了苍蝇还难看"
   - ❌ "真性情" ❌ "同行的衬托"（太抽象）
4. **不硬凹金句做转折**：每段结尾硬塞一句=像完成任务
5. **个人判断变体要多样**：变换"要博主我说/说白了/说到底/博主我觉得"

#### 金句生成顺序

```
具体细节 → 情绪累积 → 一句自然反应
```

一句话脱离前文仍像"标准金句"，大概率是硬凹；必须依赖前文具体事实才有力量，才该留。

#### 金句独立成段

金句是情绪爆发点，需要呼吸空间。不要埋在段落中间和数据混在一起。独立成段后视觉上也有冲击力。

### 3.8 过渡套路

#### 正确过渡：问题触发

每段结尾留下观众自然会问的问题，下一段第一句直接回答。

#### 错误过渡（禁止）

- ❌ 路标词堆砌："更让人寒心的是""雪上加霜的是""更让人震惊的是"——全文不超过2处
- ❌ 预告式过渡："接下来我要讲一个更离谱的事"——直接讲，别预告
- ❌ 分析师过渡："把时间线一摆就明白了"——改为抓贼感："狐狸尾巴就露出来了"
- ❌ 硬转折：段间用"---"分隔+突兀切换——用反问自然过渡

### 3.9 标点节奏量化

| 标点 | 用法 | 频率 |
|------|------|------|
| **感叹号** | 强调情绪、反问、吐槽 | 密集使用，情绪高点必须有 |
| **省略号** | 表示无语、留白 | 适度，用于"这都能……"式无语 |
| **逗号** | 长句分割，制造节奏感 | 口语化短句优先用逗号断开 |
| **问号** | 反问、设问、互动 | 每段可出现，保持互动感 |
| **句号** | 短句收束 | 多用短句，句号密集=节奏快 |

**数字一律用阿拉伯数字**：❌ 十五万美元 → ✅ 15万美元

**日期口语化**：❌"2026年"→✅"今年"（减少认知负担；但政策/合同节点要精确）

### 3.10 用词边界

#### 允许（白名单）

- ✅ 第一句话单独一行，冲击力强
- ✅ 先说最新事件，再说之前的事
- ✅ 数据准确，多用案例支撑
- ✅ 口语化表达，轻松诙谐
- ✅ 有态度、有立场、有情绪
- ✅ 具体数字、具体人物、具体对话
- ✅ 快慢交替、情绪起伏

#### 禁止（黑名单）

**观众会划走的具体原因——不是风格偏好，是数据：**

1. **烂大街hook**："这不是小说""这不是做梦""你敢相信吗"——每个视频都用的开场白已经免疫了
2. **独立成段的算账**：机制解释必须嵌在场景/人物/故事里。单独一段分析=教科书=划走
3. **空洞修辞**："令人震惊的""令人心痛的""不可否认"——删掉不影响任何信息量
4. **硬凹对仗金句**：工整的排比句只在演讲比赛里有用。视频里太工整=假=不信
5. **结尾说教**："我们应该""希望有关部门""值得每个人反思"——观众没让你教他怎么想
6. **路标词堆砌**："更让人寒心的是""雪上加霜的是""更让人震惊的是"——全文不超过2处。每多一处，观众多划走一截
7. **预告式过渡**："接下来我要讲一个更离谱的事"——直接讲，别预告
8. **抽象归因**："资本是逐利的""市场就是这样"——这类话等于什么都没说。必须说清楚谁、怎么、多少
9. **第三人称旁白**："该公司将面临"→换成"他的资格没了"。旁白=新闻，第一人称=代入
10. **日期年份数字**："2026年"→"今年"。口语化的日期减少认知负担（但政策/合同节点要精确）
11. **假大空**：没有数据支撑的论断
12. **政治正确式结尾/喊口号**："我们应该""愿每个"
13. **严肃基调**：全程中立客观
14. **强凹金句黑名单**：
    - ❌ 工整对仗型："最孤独的冠军，最打脸的金牌"
    - ❌ 打脸口号型："全队把她当垫脚石，她却逆袭独摘金牌"
    - ❌ 说教反问型："三次第一还不能去，你说这选拔是选人还是选关系？"
    - ❌ 鸡汤升华型："努力有时会被忽视，但真正强大的人从不需要他人施舍荣光"
    - ❌ 同义反复型："临时工就像一次性筷子"+"企业用临时工，就像用一次性手套"
    - ❌ 过渡硬凹型："这哪是招聘，这是诈骗""资本家的算盘珠子，都快崩到工人脸上了"
15. **"要博主我说"中间滥用**：中间用多了像在说教，只在最关键的定性位置用一次，结尾必用
16. **网络梗收束**："散会""没门"——用克制情绪

### 3.11 口语化的本质

口语化不是用"好家伙""你品品"这些词。

口语化的本质是：**用说话的方式组织思维**。

- 说话时不会先写提纲再讲→想到什么说什么→句子短、碎、有停顿
- 说话时会用反问确认对方在听→"你猜怎么着？""啥概念？"
- 说话时会有态度→"说白了""说到底""拉倒吧"
- 说话时不会用从句嵌套→一个意思一句话说完，不转弯

但口语化不等于没有逻辑。说话的人也会有推理链，只是不写出来。一段话表面是碎句，底下有因果——这就是好文案。

### 3.12 正面情感类开头

正面情感题材（科技突破/国家成就/清流人物），开头同样遵循"不铺垫、直接抛冲突"原则，但冲突可以是"反差式自豪"：
- ✅ "275到45，暴跌八成以上！"（数据冲击型，用于国产替代）
- ✅ "国家这波干得是真漂亮！"（拍手叫好型，独立成句）

## 第四部分：AI痕迹清除

### 4.1 AI味浓的四个原因

| 原因 | 表现 | 解法 |
|------|------|------|
| **太工整太对称** | 每段结构一样、字数差不多、转折词位置固定 | 每段结构要错落有致 |
| **转折太生硬** | 没有铺垫就突然跳到下一个话题 | 用反问句过渡，先预判观众想法 |
| **吐槽太刻意** | 没有情绪铺垫就直接上吐槽 | 先用数据/案例铺垫，在最高点爆发 |
| **缺乏个人化表达** | 没有具体细节、没有真实场景 | 加入具体人名、具体场景、具体对话 |

### 4.2 必须清除的AI痕迹表

| 痕迹类型 | 信号词 | 修法 |
|----------|--------|------|
| 过度拔高 | 标志着/象征着/体现了/里程碑 | 删掉，从事实起笔 |
| 模糊归因 | 专家认为/研究表明/有人指出 | 给来源或降级 |
| 分析师讲解语姿 | 把X拆完/看完/说完，再Y | 直接从新事实起笔 |
| 伪口语化 | 拆一拆/盘一盘/聊一聊/捋一捋 | 删掉，从事实起笔 |
| AI高频关联句 | 一旦…就/只有…才/无论…都 | 改用轻量黏合词 |
| 二分对照壳 | 不是A而是B（高频重复） | 改为不对称对照，全文≤3次 |
| 戏剧化揭露 | 扯下/撕下+遮羞布/面具 | 改为具体判断 |
| 协作交流痕迹 | 让我们/接下来/下面我将 | 全部删除 |
| 鸡汤收尾 | 在这个越来越…的世界里 | 改为具体判断收束 |
| 宣传式 | 无缝/直观/强大/革命性/赋能 | 改为功能/限制/代价 |

### 4.3 书面腔→口语 替换

| 书面腔 | 口语化 |
|--------|--------|
| 系统性溃败 | 整个系统在塌 |
| 资本是趋利避害的 | 投入和产出倒挂到这份上 |
| 加工更是地狱模式 | 排队打饭就要10多分钟，来回路程再10多分钟 |
| 待遇差距显著，约为8倍 | 一个12万8，一个1万6，差了将近8倍 |
| 数据显示 | 你品品/好家伙/这谁扛得住 |
| 根据统计 | 你瞅瞅这数据 |

### 4.4 最小改写原则

- 删路标词（"值得注意的是/总体而言/换句话说"），不重写后半句论证骨架
- **单点修补不扩散成整段重写**：只改AI痕迹，不动风格
- 改的是"痕迹"，不是"风格"——改完后文章应该更有锋芒，而不是更平庸

### 4.5 平庸化回滚检测

如果改完后出现以下症状，说明"除味"反客为主了，必须回滚：

- 段落明显变薄，信息密度下降
- 句子整体变短且均匀，长句链断裂
- 作者视角与锋利判断被抹平成中性说明书

### 4.6 AI文本 vs 真人文本的底层差异

真人文本像**一个人在讲故事**，AI的像**AI在堆砌信息**：

- 真人每句话有明确逻辑关系（因果/递进/转折），AI句子之间毫无关联
- 真人加入个人反应（"把我都看感动了""好家伙！"），AI只陈述事实
- 真人过渡自然流畅（"为啥子嘞？""你想想"），AI过渡生硬刻板
- 真人引用具体素材（视频链接/时间戳），AI只写泛泛描述

### 4.7 `<u>`标签使用规则

- `<u>`标签只在大纲阶段使用，标注有传播价值的句子
- 最终文章中**全部删除**`<u>`标签
- 大纲阶段规划≥6处`<u>`吐槽句，均匀分布：开头1处、中间3-4处、结尾1-2处

### 封面与标题规则

**封面**：4-5个字的核心关键词 + 一句简单描述。直接说事实为主；强冲突比喻词（如"遮羞布"）可用，不用抽象概念/对仗。
- 示例：光刻胶断供，日本搬石砸脚

**标题**：一句话概括文章内容，必须包含关键词，亮点前置。选最有情绪冲击力的词。
- ❌ "护照上就印着'禁止以色列'"
- ✅ "这个国家容不下犹太人"
