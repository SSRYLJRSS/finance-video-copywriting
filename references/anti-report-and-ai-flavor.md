# 防报告式写法 + 去AI味 + 金句规则

## 一、报告式 vs 文章式（核心区别）

**报告是分析问题，文章是讲故事/吐槽。**

| 维度 | ❌ 报告式 | ✅ 文章式 |
|------|---------|---------|
| 开头 | "女性完成去义务化，不允许男性去责任化" | "你品品，现在这世道，女性挣脱了传统义务，不想做饭、不想顾家、不想温柔，这叫独立" |
| 结构 | 1.现象 2.原因 3.影响 4.建议 | 钩子→冲突→高潮→收束 |
| 语言 | "数据显示""研究表明""根据统计" | "你品品""好家伙""这谁扛得住" |
| 情绪 | 全程中立客观 | 震惊→愤怒→共鸣→反思 |
| 举例 | 抽象概括 | 具体数字、具体人物、具体对话 |
| 结尾 | "综上所述""建议" | "散会""想开了就是海阔天空，想不开就是评论区见" |

### 报告式特征（必须避免）
1. 结构像分析报告：1.现象 2.原因 3.影响 4.建议
2. 语言像新闻稿："数据显示""研究表明"
3. 每段结构雷同：论点→论据→小结
4. 缺乏情绪起伏：全程一个语气
5. 缺乏个人色彩：没有"你品品""好家伙"等口语词
6. 缺乏具体场景：只有抽象概括

### 大纲阶段也要防
大纲本身就是口语化的：
- ❌ 大纲用书面语："核心判断：不是男女天生对立，是权利义务的套娃游戏"
- ❌ 大纲用学术框架："争议点：女性完成去义务化，却不允许男性去责任化"
- ❌ 大纲段落描述太长：每段写200字"解释"
- ✅ 大纲示例：
  ```
  ### 1. 钩子：套娃游戏（350字）
  你品品，女性挣脱义务叫独立，男性卸下责任叫摆烂。这哪是平权，这他妈是套娃游戏。
  爆点："要权力对标西方，逃避付出对标封建"
  东北味：你品品、好家伙、这谁扛得住
  ```

## 二、口语化的本质

口语化不是加语气词，是**用说话的方式组织思维**：
- 想到什么说什么，句子短、碎、有停顿
- 用反问确认对方在听："你猜怎么着？""啥概念？"
- 有态度："说白了""说到底""拉倒吧"
- 但口语化不等于没逻辑：表面碎句，底下有因果链

**口语化 vs 报告式对比**：
| 维度 | 报告式 | 口语化 |
|------|--------|--------|
| 开头 | 直接陈述事实 | 先抛冲突/情绪 |
| 人称 | 第三人称/无主语 | "你品品""好家伙""你瞅瞅" |
| 句式 | 长句、复合句 | 短句、碎句、反问句 |
| 情绪 | 中立客观 | 有态度、有吐槽、有立场 |
| 节奏 | 匀速推进 | 快慢交替、情绪起伏 |

## 三、金句铁律

### 核心原则
1. **金句是平凡文字表达强烈情感**，不是工整对仗
   - ✅ "剩余的工资被狗吃了吗？" ✅ "这tm不是在工作啊，这是在挑战人类的生理极限！"
   - ❌ "财报好看了，工人的命却贱了" ❌ "车企的小算盘，打得比流水线还精"
2. **金句只出现一次**：放在最有冲击力的位置，重复=机器人感
3. **金句要具体、有画面感**
   - ✅ "冯德莱恩那张职业假笑的脸瞬间比吃了苍蝇还难看"
   - ❌ "真性情" ❌ "同行的衬托"（太抽象）
4. **不硬凹金句做转折**：每段结尾硬塞一句=像完成任务
5. **个人判断变体要多样**：变换"要博主我说/说白了/说到底/博主我觉得"

### 金句生成顺序
```
具体细节 → 情绪累积 → 一句自然反应
```
一句话脱离前文仍像"标准金句"，大概率是硬凹；必须依赖前文具体事实才有力量，才该留。

### 强凹金句黑名单（禁止使用）
- ❌ 工整对仗型："最孤独的冠军，最打脸的金牌"
- ❌ 打脸口号型："全队把她当垫脚石，她却逆袭独摘金牌"
- ❌ 说教反问型："三次第一还不能去，你说这选拔是选人还是选关系？"
- ❌ 鸡汤升华型："努力有时会被忽视，但真正强大的人从不需要他人施舍荣光"
- ❌ 同义反复型："临时工就像一次性筷子" + "企业用临时工，就像用一次性手套"
- ❌ 过渡硬凹型："这哪是招聘，这是诈骗" "资本家的算盘珠子，都快崩到工人脸上了"

### 金句独立成段
金句是情绪爆发点，需要呼吸空间。不要埋在段落中间和数据混在一起。独立成段后视觉上也有冲击力。

## 四、去AI味关键操作

### AI味浓的四个原因

| 原因 | 表现 | 解法 |
|------|------|------|
| **太工整太对称** | 每段结构一样、字数差不多、转折词位置固定 | 每段结构要错落有致 |
| **转折太生硬** | 没有铺垫就突然跳到下一个话题 | 用反问句过渡，先预判观众想法 |
| **吐槽太刻意** | 没有情绪铺垫就直接上吐槽 | 先用数据/案例铺垫，在最高点爆发 |
| **缺乏个人化表达** | 没有具体细节、没有真实场景 | 加入具体人名、具体场景、具体对话 |

### 必须清除的AI痕迹

| 痕迹类型 | 信号词 | 修法 |
|----------|--------|------|
| 过度拔高 | 标志着/象征着/体现了/里程碑 | 删掉，从事实起笔 |
| 模糊归因 | 专家认为/研究表明/有人指出 | 给来源或降级 |
| 分析师讲解语姿 | 把X拆完/看完/说完，再Y | 直接从新事实起笔 |
| 伪口语化 | 拆一拆/盘一盘/聊一聊/捋一捋 | 删掉，从事实起笔 |
| AI高频关联句 | 一旦…就/只有…才/无论…都 | 改用轻量黏合词 |
| 二分对照壳 | 不是A而是B（高频重复） | 改为不对称对照，全文≤3次 |
| 戏剧化揭露 | 扯下/撕下+遮羞布/面具 | 改为具体判断 |
| 协作交流痕迹 | 让我们/接下来/下面我将 | 全部删除 |
| 鸡汤收尾 | 在这个越来越…的世界里 | 改为具体判断收束 |
| 宣传式 | 无缝/直观/强大/革命性/赋能 | 改为功能/限制/代价 |

### 书面腔→口语 替换

| 书面腔 | 口语化 |
|--------|--------|
| 系统性溃败 | 整个系统在塌 |
| 资本是趋利避害的 | 投入和产出倒挂到这份上 |
| 加班更是地狱模式 | 排队打饭就要10多分钟，来回路程再10多分钟 |
| 待遇差距显著，约为8倍 | 一个12万8，一个1万6，差了将近8倍 |
| 数据显示 | 你品品/好家伙/这谁扛得住 |
| 根据统计 | 你瞅瞅这数据 |

### 最小改写原则
- 删路标词（"值得注意的是/总体而言/换句话说"），不重写后半句论证骨架
- **单点修补不扩散成整段重写**：只改AI痕迹，不动风格

### 平庸化回滚检测
如果改完后出现以下症状，说明"除味"反客为主了，必须回滚：
- 段落明显变薄，信息密度下降
- 句子整体变短且均匀，长句链断裂
- 作者视角与锋利判断被抹平成中性说明书

## 五、AI味检查清单（写完必过）

1. 太工整太对称？每段结构一样 → 真人说话不会这样
2. 转折太生硬？段间用"---"分隔 → 用反问过渡
3. 吐槽太刻意？没有情绪铺垫就上吐槽 → 先铺垫再爆发
4. 缺个人化表达？没具体人名/场景 → 加入具体细节
5. 报告式语言？"数据显示""研究表明" → 全改口语
6. 路标词全文≤2："雪上加霜的是""更让人寒心的是"每多一处观众多划走一截
7. `<u>`下划线标记在最终文章中全部删除（只在大纲阶段用）

- [ ] 整体读起来像不像一个人在跟朋友聊天吐槽？
