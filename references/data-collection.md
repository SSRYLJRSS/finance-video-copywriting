# 资料收集工作流

## 适用场景
中国财经新闻事件、社会热点、国际政治、人物故事等泛财经话题的系统化资料收集。

## 工作流概览（4步）

### Step 0：搜索清单先行
先列 ≤7 个待回答问题，防止搜着搜着跑偏。

| 维度 | 问题示例 | 目标来源类型 |
|------|----------|-------------|
| 事件与时间线 | "什么时候发生的？关键节点？" | 官方通报/权威媒体 |
| 核心数据 | "涉及多少钱/人/比例？" | 统计局/财报/行业报告 |
| 官方回应 | "官方怎么说？处理结果？" | 政府公告/法院文书 |
| 行业背景 | "这个机制是什么？怎么运作？" | 行业分析/专家研究 |
| 公众影响 | "网友怎么看？情绪倾向？" | 社交媒体/高赞评论 |
| 同类案例 | "还有类似的事件吗？" | 历史事件对比 |
| 法律依据 | "违反了什么规定？" | 法律条文/司法解释 |

### Step 1：并行搜索（按主题类型选渠道）

**通用原则**：同时开搜2-3个渠道，卡住立刻换。

**主题类型渠道组合**：
- 财经新闻/企业事件：搜索引擎 + 百度 + 微信公众号
- 社会热点/舆论事件：搜索引擎 + 知乎 + 微博/B站（高赞优先）
- 国际政治：搜索引擎（英文） + 百度
- 人物故事：百度 + 知乎 + 微信公众号

**搜索关键词技巧**：
- 必加最新年份（2025/2026）
- 事件与时间线：`{主题} 事件 时间线 {年份}`
- 官方回应：`{机构} 通报 {主题} 处理结果`
- 同类案例：`{类型} 类似事件 处理`
- 高赞舆论：`{主题} 知乎 高赞 评论`

**国际话题用英文搜索**效果更好：`Malaysia anti-Israel history`

### Step 2：多源交叉验证（关键数字必做）
- 金额/人数/占比/时间点 → 至少2个独立来源印证（官方+媒体或两家媒体）
- 只1个来源=待核验，不许进大纲
- 冲突保留标注，找来源3仲裁
- 数据口径冲突时以官方数据为准

### Step 3：素材评分 + 排事件链

## 素材评分体系

| 维度 | 权重 | 5分示例 | 1分示例 |
|------|------|---------|---------|
| 共鸣度 | ×2 | 工资、社保、加班 | 技术细节 |
| 情绪强度 | ×1.5 | 愤怒、心疼 | 无聊 |
| 反差度 | ×1 | 强烈反差 | 无反差 |
| 具体性 | ×0.5 | 数字+人名 | 抽象描述 |
| 传播性 | ×0.5 | 金句级别 | 难以传播 |

**等级划分**：
- S级（25-27.5）：核心素材，必须使用
- A级（20-24）：优质素材，优先使用
- B级（15-19）：普通素材，可以使用
- C级（10-14）：弱素材，尽量不用
- D级（<10）：淘汰

## 可信等级标准

| 等级 | 来源类型 | 示例 |
|------|----------|------|
| A级 | 官方通报、政府公告、法院文书 | 国务院通报、统计局数据 |
| B级 | 权威媒体原始报道、行业报告 | 新华社、财经、21世纪 |
| C级 | 用户帖子、自媒体评论 | 知乎回答、微博评论 |

## 资料卡格式

```markdown
# {编号}-{短标题}

- **维度**：
- **结论**：
- **事实**：
  1. ...
  2. ...
- **数据**：
  - ...
- **来源**：[{媒体标题}]({URL})
- **发布日期**：
- **可信等级**：A/B/C
- **可用于**：钩子/事实还原/机制解释/对比/结尾
- **立场一致性**：支持方=___ / 反对方=___ / 中立=___（必须标注）
- **风险**：
```

### ⚠️ 立场一致性检查（写死，禁止跳过）
**每个案例素材入库前必须标注"支持方/反对方"**，并与文章立场核对：
- 文章要"痛批XX" → 案例里的加害方必须是 XX，受害者立场不能反
- **与文章立场冲突的案例一律禁止进大纲**（实证：某次实战中 AI 用过"男方灭门5口"这种立场反了的案例，被用户纠正"要女方有过错"近期）
- 案例事实方向存疑的（谁砍谁、谁骗谁），先核实事实再标立场，禁止凭印象

## 网友态度与吐槽金句收集

### 收集渠道（按优先级）
1. **B站弹幕**：实时网友评论，情绪最真实
2. **知乎高赞**：深度分析和吐槽
3. **微博评论**：情绪化表达
4. **抖音评论**：接地气的吐槽

### 吐槽金句分类
1. **愤怒型**：对造假/不公行为的愤怒
2. **嘲讽型**：对虚假人设/说辞的嘲讽
3. **共情型**：对被误导普通人的心疼
4. **看清型**：对机制问题的看清

### 金句使用原则
1. 金句只出现一次，放最有冲击力的位置
2. 金句要具体、有画面感
3. 金句要自然融入，不要用标签标注
4. 评论要穿插在叙事中当吐槽用，不能平铺直叙做证据链

## 注意事项

1. **不要只写"来源：知乎/媒体"**，必须留URL
2. **不要用搜索摘要替代原文阅读**
3. **不要为了凑数量重复同一事实**
4. **不要把高赞评论写成事实**（社交舆论仅用于情绪分析）
5. **数据必须交叉核验**，口径冲突时保留冲突
6. **稀素材话题必须多渠道并行搜索**

## 稀素材散发型话题特殊处理

当核心事件信息量少时（如官员落马只有一纸通报），通过"散发"扩展：

### 五种散发方向（按优先级）
1. **同类案例对比**（最优先）：找3-5个相似案例
2. **时间线反差**：当年高光 vs 如今落马
3. **舆论考古**：当年网友怎么夸的，现在怎么骂的
4. **机制分析**：从个案延伸到制度/行业
5. **关键人物对照**：找一个"镜像人物"做对比

### 主题分析5角度框架
| 角度 | 核心逻辑 | 传播力 |
|------|----------|--------|
| 打脸反转型 | 人设崩塌，当年的XX如今成了XX | ⭐⭐⭐⭐⭐ |
| 特权愤怒型 | XX的背景/关系，凭什么XX？ | ⭐⭐⭐⭐⭐ |
| 双线对比型 | 两条命运线交织，各自跌落 | ⭐⭐⭐⭐ |
| 制度反思型 | XX只是冰山一角 | ⭐⭐⭐ |
| 人性复杂型 | 功是功，过是过 | ⭐⭐⭐ |

### 稀素材评分特殊规则
- 反差度是**核心维度**（权重提升）
- 没有反差就没有散发的抓手
- S级素材通常是"反差度最高"的那个点
