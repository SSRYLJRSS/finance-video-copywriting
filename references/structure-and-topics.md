# 结构模板库 + 话题模式大全

## 一、四类基础结构模板（基于123篇统计）

| 类型 | 占比 | 适用场景 | 结构 |
|------|------|----------|------|
| **时事揭露** | 50% | 消费、监管、公共事件 | 钩子→事件→案例链→机制→定性 |
| **对比打脸** | 25% | 产业、中外、新旧替代 | 旧优势→新事实→对比数据→原因→时代判断 |
| **账本拆解** | 15% | 债务、金融、行业 | 大数→账本→传导→风险→行动建议 |
| **人物群像** | 10% | 体育、教育、社会 | 反差场景→经历→结构原因→共情→克制收束 |

## 二、特殊结构模板

### 清流对比型
先写清流反常操作（钩子）→ 行业乱象（愤怒前置）→ 更多善举（破防）→ 情绪定性收束（不说教）。
**不要先乱象后清流。** 收束用事实对比定性，不要分析式结论。

### 雪上加霜式递进
每一段都比上一段更惨：未来画面→现状打脸→培养账本→定价扭曲→DRG扣钱→医闹→克制收束。
核心逻辑：A已经很惨了→B让A更惨→C让B更惨→情绪不断升级。

### 事实罗列式开头（人物传奇类）
直接甩吊炸天事实不解释不铺垫，砸懵再揭秘身份。节奏快爽点前置。

### 反派人设型叙事结构
1. 钩子（新闻事件引入）→ 2. 反派形象建立（逐步揭露恶行）→ 3. 原因分析（简短不学术）→ 4. 评价收尾（要博主我说）
不要用"又当又立"作为开头，要用新闻事件开头；反派形象要逐步建立，不要一次性全部揭露。

### 多案例主线+副线
先聚焦主线人物（1-2段讲清"当年→如今"反差）→ 自然过渡其他案例（"你猜怎么着？这种人还真不少"）→ 每个案例只抓一个核心打脸点 → 结尾落在通用结论。

## 三、大纲核心逻辑教训（10条）

1. 画面先行比数据先行更有冲击力
2. 人物线用"人"串联数据，不要只有数据没有温度
3. 机制穿插在故事中不单独成段
4. 反差要一次性炸，不要提前剧透
5. 收束要克制
6. 每段只承担一个功能
7. 逻辑链是"问-答"式递进，不是"列清单"式并列
8. 开头要合并紧凑：同一维度信息合成一段
9. 过渡要怼观众："你觉得大佬在吓唬人？现实数据就摆在这里"
10. 历史规律独立成段，不要嵌在其他段落里当附件

## 四、大纲被退的常见原因

| 反馈 | 原因 | 解法 |
|------|------|------|
| 太散 | 没聚焦核心争议 | 搜高赞回答提取3-5个点 |
| 不够吸引人 | 角度太平淡 | 参考高赞回答的角度 |
| 偏离参考文案 | 跑偏了 | 以参考文案为锚点 |
| 节奏慢 | 段落太长 | 3-5句话一段 |
| 拖节奏 | 同一事实翻来覆去 | 同一事实不说第二遍 |

## 五、话题模式：地缘政治对抗

适用于：一国硬刚另一国，带"装逼被打脸"或"小国硬刚"情绪的事件。

### 变体A：三段式（硬气方历史丰富时）
```
第一段：引子（10%-15%）——短钩子（装逼被打脸），快进快出
第二段：硬气方有多刚（50%-60%）——历史案例堆叠，每个一句话点到为止
第三段：被打脸方有多坏（30%-40%）——情绪输出，不是分析
```

### 变体B：四段式（事件本身信息量大时）
```
第一段：事件本身（40%）——讲透，不一句话带过
第二段：硬气方有多刚（20%）——精选3-5个最震撼案例
第三段：被打脸方有多坏（20%）——具体数据+案例
第四段：收束嘲讽（20%）——用对方"下一步动作"做嘲讽收尾
```

### 关键约束
- 导火索/网红只是切入角度，不是主角
- 案例精选3-4个，不要堆6-7个
- 同一事件加画面细节（"在机上躲雷暴雨"）
- 删除第三方反应padding（投资冻结、谴责等）
- 不要用牵强历史类比
- 搜索国际话题用英文效果更好

## 六、话题模式：财政供养/体制内待遇

适用于：地方财政困境、编内编外差距、体制内改革。

### 核心爽点公式
`[具体县]收X亿税，光发工资就要Y亿，编内Z万/年，编外W万/年——N倍差距，钱全是全国纳税人兜底`

### 结构模板
```
1. 钩子（350字）：核心数据反差——税收X亿 vs 工资Y亿
2. 事件细节（400字）：临聘人员具体工资、历史欠债事件
3. 编内编外对比（350字）：8倍差距、同工不同酬
4. 机制分析（350字）：自给率、吃饭财政、转移支付
5. 改革+收束（350字）：改革案例 + 网友情绪金句 + 定性
```

### Pitfall
- 不要写成单纯"公务员该降薪"，聚焦"钱从哪来、谁在买单"
- 不要把一个县写成孤例（要联系全国平均自给率）
- 不要忽略编外人员贡献（"最苦的人拿最少"）

## 七、话题模式：人造天才翻车/多案例打脸

适用于：学术造假、人设包装、教育公平争议。

### 结构模板
```
钩子：最新翻车事件
→ 案例1一段（最有名/最典型）
→ 案例2一段
→ 案例3一段（每个案例只写核心打脸点）
→ 共通逻辑：成年人操盘，孩子当工具
→ 收束：翻车是时间问题
```

### 关键原则
- 先聚焦主线人物（1-2段），后面再散发其他人
- 每个案例一个核心打脸点，不展开太多
- 不要一上来就多个案例并列——会散

## 八、话题模式：人设崩塌/屠龙少年终成恶龙

适用于：曾经被追捧的公众人物翻车，组合成"打脸爽文"。

### 结构模板
```
钩子：最新翻车事件
→ 回忆当年：还原名场面，建立反差基础
→ 反转落马：如今的下场，核心打脸
→ 散发引入：这种人不止他一个
→ 批量打脸：2-3个同类案例快速过
→ 收束：做人不能太狂
```

### 核心判断写法
- ❌ 暴论式："权力必然腐蚀"——太绝对
- ✅ 个人责任式："做人不能太狂，再大的功劳也扛不住一颗狂妄的心"
- **原则**：结论落到"个人态度"上，不落到"系统性问题"上

## 九、话题模式：社会现象（性别对立/价值观冲突）

适用于：男女对立、社会矛盾、价值观变迁等"软性社会议题"。

### 与财经/时事类区别
| 维度 | 财经/时事类 | 社会现象类 |
|------|-------------|------------|
| 核心 | 具体事件+数据 | 现象+情绪+案例群 |
| 争议点 | 利益冲突 | 价值观冲突 |
| 爽点 | 打脸、揭露 | 共鸣、愤怒、看清 |

### 立场要求
社会现象类可能有明确立场要求。立场明确时：
1. 主题选项全部围绕该立场设计
2. 不要给"中立"或"双方都有问题"的选项
3. 金句和爆点都要服务于该立场
4. 数据和案例要支撑该立场

### "去义务化/去责任化"分析框架（可复用于所有权利义务不对等话题）
1. **过去**：权责对等的传统模式
2. **变化**：一方完成了去义务化
3. **矛盾**：另一方的责任纹丝不动
4. **反应**：被压榨方开始"止损"
5. **后果**：社会撕裂
6. **历史镜像**：日韩已经走过这条路

## 十、话题模式：续集蹭流量

触发：用户说"视频火了写第二个""写个续集""模仿文案1优化改写"。

### 核心要求
续集不是"重新写一篇"，而是"保持骨架、换皮升级"：
- **结构**：与文案1完全一致（段落数、顺序、情绪线）
- **数据**：更新到最新
- **表述**：换一批表述，保持相似风格
- **新内容**：加入文案1没有的新角度/新数据
- **锐评**：更犀利

### 续集核心价值：找到"新时间线"
续集不是"把文案1的话换种说法再说一遍"，而是"文案1之后又发生了什么"。

## 十一、话题模式：正面情感事件

当事件本身是正面/感人故事时，"反派"不是具体的人，而是**系统性障碍**（价格、制度、偏见等）。

### 选题模式
- **情感驱动型**：感人故事 → 背后困境 → 系统性障碍 → 反思
- **社会议题型**：具体案例 → 数据支撑 → 系统性问题 → 争议讨论
- **对比冲突型**：旧方案困境 → 新方案突破 → 价格壁垒 → 未来展望

### 开头铁律
正面情感事件开头**不要从吐槽/对比开始**，直接从最感人的画面切入。

## 十二、选题类型排序（按流量）

| 类型 | 说明 | 示例 |
|------|------|------|
| 又当又立型 | 拆解伪君子，反差最大 | 企业喊社会责任，实际用临时工规避社保 |
| 反派人设型 | 调动愤怒情绪，流量最强 | 协会批量起诉小微企业敲竹杠 |
| 双标打脸型 | 用事实打脸，网友最爱看 | 对外宣传vs实际做法完全相反 |
| 大国博弈型 | 民族情绪+竞争，深度+流量 | 伊朗炸美国机房，几万换八千亿 |
| 爽文打脸型 | 让普通人爽 | 高分考生被关系户顶替，反转打脸 |
| 正面情感型 | 感人+系统性障碍 | 科技助残vs价格壁垒 |

## 十三、选题四问检验

选题前必须回答（少于两项成立不做，四项都成立优先做）：

| # | 问题 | 判断标准 |
|---|------|----------|
| 1 | 反差在哪里？ | 期望vs现实之间有没有"凭什么"的差距 |
| 2 | 普通人为什么会在意？ | 钱、时间、尊严、安全是否被损害 |
| 3 | 有哪些可核验数据或案例？ | 至少有2个A级来源支撑核心事实 |
| 4 | 真正值得争论的机制是什么？ | 规则、利益、制度层面的矛盾 |
