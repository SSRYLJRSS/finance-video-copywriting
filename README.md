# finance-video-copywriting

> 泛财经新闻视频口播文案 AI 写作 Skill —— 让 AI 按专业流水线帮你写"爽文打脸型"财经短视频文案。

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## 这是什么

一个 **AI 文案写作技能包**（Skill）。装进 AI 助手后，AI 会按一套经过实战验证的 **S0→S7 七步流水线** 帮你写口播文案：

- 不是"随便写一篇"，而是逐步推进、每步等你确认
- 自带**完整口播风格系统**（基于上百篇爆款文案提炼：立场/语气/口语化/金句/去AI味）
- 自带**话题结构模板**（地缘政治/财政/人物翻车/社会热点/打脸反转型等）
- 自带 **20 条防错清单**（避免"写报告""假大空""AI 味重"）

**产出**：1500-2000 字口播稿，含封面词 + 标题 + 正文。

## 核心特性

- 🔥 **爽文打脸型策略**：找"装逼打脸"的事，让普通人爽
- 🎯 **双模式**：精炼模式（参考爆款骨架换皮换肉+20%创新）/ 创新模式（从零给 5 个选题）
- 🧠 **自我进化（S7/S8）**：把你手动改过的稿子发给 AI，它逐段对比、提取规律、写入经验库，越写越懂你；"全写入，改规则"可直接把偏好固化为正式规则
- 📊 **数据严谨**：关键数字交叉验证（≥2 来源），案例立场一致性检查
- 🧹 **去 AI 味**：口语化密度、路标词限额、金句黑名单、报告体消除

## 快速上手

### 安装

把整个 `finance-video-copywriting/` 文件夹放到你的 AI 工具的 skills 目录：

| 工具 | 位置 |
|------|------|
| WorkBuddy | `~/.workbuddy/skills/` |
| Hermes Agent | `~/.hermes/profiles/{profile}/skills/writing/` |
| Cursor / Claude Code | 项目目录，对话开头说明读取 SKILL.md |
| 网页版 AI | 把 SKILL.md 内容粘贴到对话开头 |

### 第一个项目（3 分钟）

1. 复制「项目工作空间模板」文件夹，改名为你的项目名
2. 把参考文案（别人的爆款文案）丢进 `参考文案/` 目录
3. 跟 AI 说："帮我写一篇关于 XXX 的文案，参考文案在 XXX"
4. AI 会先问你选哪种模式，回答"精炼模式"即可

### 常用指令

| 你说 | 效果 |
|------|------|
| "精炼模式，精炼文案1" | 用第 1 篇参考文案的骨架写 |
| "就这样" / "开始" | 当前步骤通过，进下一步 |
| "1700字，包含标点" | 指定字数（含标点口径） |
| "开头不够炸" | 重写开头，第一句要有冲击力 |
| "进入s7：+你的完整修改版" | 提交改稿让 AI 学习（强烈建议） |
| "全写入，改规则" | 让改稿经验直接变成 skill 正式规则 |
| "这是对标文案，感觉表达比你好，你在学一学：+文案" | 让 AI 学对标表达技巧 |

## 工作流程

```
S0接收主题 → S1分析参考文案 → S2资料收集 → S3主题选项(仅创新模式) → S4写大纲 → S5写文章 → S6封面标题 → S7自我学习
```

> 精炼模式永远跳过 S3（骨架已定，不给主题选项）。每步等用户确认，不会跳步乱写。
