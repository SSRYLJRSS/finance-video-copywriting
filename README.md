# 泛财经新闻视频文案 Skill（finance-video-copywriting）

> 新用户快速上手指南 —— 5 分钟看懂，10 分钟上手

> 写给谁：**会用 AI 工具、但第一次接触这个 Skill 的人**。5 分钟看完，你就知道它是干嘛的、怎么开始、整个流程长什么样。  
> 版本：v2.1.0 ｜ 适用：抖音 / B站 / 视频号的泛财经、社会热点、国际时政类口播文案

---

## 一、这是什么？一句话说清

**把你的 AI 变成一个"会写爽文打脸型财经口播稿"的文案搭子。**

装之前，你的 AI 是个通用实习生——你问一句它答一段，写出来的稿子四平八稳、没有爆款味。

装之后，它按一套**实战验证过的七步流水线（SOP）**&#x5E72;活：先拆爆款学框架、再搜资料核数据、写大纲给你过目、出成稿、出封面标题，最后还能从你的改稿里学习、越写越像你。

**产出**：一篇 1500-2000 字的口播稿（封面词 + 标题 + 正文），读出来有情绪、有爽点，符合短视频传播规律。

## 二、它和"直接让 AI 写"差在哪？

|    | 直接让 AI 写     | 用这个 Skill               |
| -- | ------------ | ----------------------- |
| 开头 | 大概率"近年来……"   | 第一句就有冲击力，3 秒留住人         |
| 风格 | 随机应变，看 AI 心情 | 内置完整口播风格系统（口语化/金句/去AI味） |
| 数据 | 可能编造         | S2 强制搜索 + 交叉验证，每个数字有来源  |
| 流程 | 一步到位写完，没法改   | 七步逐步推进，每步你确认后才继续        |
| 进化 | 每次都要重新调教     | S7 从你的改稿里学习，经验积累，越用越像你  |

核心创作理念就四个字：**爽文打脸**。让普通人爽，找"装逼打脸"的事——势利眼被打脸、弱者逆袭、反派遭报应。AI 写之前会先跟你对齐一句话：

> **[谁]的[什么东西]被[谁]用[什么方式]搞没了，最后还[怎么样了]**

这句话能让观众愤怒吗？只是"看热闹"就说明爽点没找对。

## 三、开始前必须知道的两个概念

### 1. 两种写作模式（启动时 AI 会问你选哪个）

| 模式             | 是什么                                                   | 什么时候用                       |
| -------------- | ----------------------------------------------------- | --------------------------- |
| **精炼模式**（默认推荐） | 你给一篇参考文案（别人的爆款/你自己的爆款），AI 拆它的"骨架"，用你的题材换皮换肉，加约 20% 创新 | **绝大多数情况**。有字帖照着写，比自己从零想稳得多 |
| **创新模式**（少用）   | 不给参考，AI 凭网感+资料给你 5 个选题方向，你挑一个                         | 完全没参考、想从零找选题时               |

### 2. SOP：S0→S7 七步流水线

整个写作过程被拆成 7 个步骤，**AI 每走完一步就停下来等你确认**，不会一口气写完：

```
S0 接收主题 → S1 分析参考文案 → S2 资料收集 → [S3 选题：仅创新模式]
→ S4 写大纲 → S5 写正文 → S6 封面标题 → S7 自我学习
```

> ⚠️ 精炼模式**永远跳过 S3**（骨架已定，不需要选题）。

## 四、快速上手：10 分钟跑通第一个项目

### 第 1 步：安装（装过 Skill 的人都会）

把 `finance-video-copywriting` 文件夹放进你的技能目录（WorkBuddy 是 `~/.workbuddy/skills/`，Hermes 是 `~/.hermes/profiles/{你的profile}/skills/`），重启对话。

> ⚠️ 如果你是旧版升级：**先删掉旧文件夹，再装新的**，不要覆盖合并，防旧规则残留冲突。

### 第 2 步：建项目文件夹（建议）

复制 Skill 里&#x7684;**「项目工作空间模板」**，改名为你的项目名（比如 `特斯拉降价`）。模板自带目录结构：

```
特斯拉降价/
├── 参考文案/     ← 把参考文案放这（可选）
├── 分析/         ← AI 拆解结果
├── 资料收集/     ← AI 搜的素材（带来源）
├── 大纲/         ← 正文骨架
├── 文章生成/     ← 最终成稿在这
└── 封面标题/     ← 封面+标题方案
```

> 不用管这些目录干嘛的，AI 会自动存。你只需要知道**成稿在「文章生成」里**。

### 第 3 步：开聊（第一句话）

有参考文案：

> "帮我写一篇关于【主题】的文案。参考文案在【路径】里，工作目录是【路径】。"

没有参考文案：

> "帮我写一篇关于【主题】的文案。"

### 第 4 步：回答 AI 的第一个问题

AI 会先问：**精炼模式还是创新模式？**

- 有参考文案 → 选**精炼模式**
- 没参考想选题 → 选**创新模式**
- 拿不准 → 选精炼模式（默认推荐）

### 第 5 步：一路做选择题

AI 走完一步就停下等你，你全程只说"**就这样**"或提修改意见。流程演示：

```
你：精炼模式
AI：S1 分析参考文案 →（一页拆解报告）→ 请确认
你：就这样
AI：S2 收集资料 →（搜索清单+资料卡）→ 请确认
你：就这样
AI：S4 写大纲 →（分段骨架，金句带下划线）→ 请确认
你：就这样，开始写文章
AI：S5 正文（1500-2000字）→ 完整成稿 + 字数统计
你：（通读，提修改或直接）出封面标题
AI：S6 五组封面+标题方案
你：用第3组。进入s7，这是我的修改版：+【你改过的全文】
AI：S7 学习完成，你的偏好已记录，下次自动生效
```

## 五、SOP 详解：每一步 AI 干什么、你干什么

| 步骤                 | AI 做什么                            | 你做什么           | 口令                |
| ------------------ | --------------------------------- | -------------- | ----------------- |
| **S0 接收主题**        | 确认主题 + 确认写作模式                     | 给主题、选模式        | —                 |
| **S1 分析参考文案**      | 逐篇拆解：角度/情绪/论点/结构/金句               | 扫一眼拆得对不对       | "就这样"             |
| **S2 资料收集**        | 列搜索清单→并行搜索→交叉验证→资料卡（带来源/可信度/立场标注） | 可指定搜索方向        | "开始s2"            |
| **S3 主题选项**（仅创新模式） | 给 5 个选项（封面+标题+角度+流量点）             | 挑一个或组合         | "选第2个"            |
| **S4 写大纲**         | 口语化大纲，`<u>`标注传播金句                 | 查结构/字数/爽点      | "就这样，开始写文章"       |
| **S5 写正文**         | 按大纲写 1500-2000 字成稿                | **大声通读**，提修改   | "开头不够炸"/"第二段改狠一点" |
| **S6 封面标题**        | 5 组封面词+标题                         | 选一组或让它改        | "s6"              |
| **S7 自我学习**        | 对比你的改稿 vs 初稿，提炼偏好写进经验库            | **把改过的最终版发给它** | "进入s7：+改稿"        |

## 六、和 AI 协作的 5 条铁律

1. **每步等确认**：AI 做完一步必须停，等你说"就这样"才进下一步。它要是连做了，直接说："谁让你两步一起做的？每次只能做一步。"
2. **字数=含标点**：说"1700字"= 含标点共 1700 字。S5 交付时 AI 会用脚本统计「中文字数 + 含标点总字符数」双值汇报，不是目测。
3. **双输出**：每步产出 AI **先在对话里完整展示，再存本地文件**——对话里看、文件夹里留档，两边都有。
4. **改稿比重写值钱**：AI 初稿出来后你自己改一遍，把完整修改版发回去说"进入s7"——AI 会从你的改稿里学习，**这是 Skill 会进化的核心机制**。
5. **"全写入，改规则"**：想让某个偏好永久生效（比如"别用雪上加霜"），改稿后补一句这个口令，经验直接升级为正式规则，从此所有项目都遵守。

## 七、常用口令速查

| 口令                   | 用途                 |
| -------------------- | ------------------ |
| "精炼模式，精炼文案1"         | 选精炼模式，指定用第 1 篇参考文案 |
| "就这样" / "开始"         | 当前步骤通过，进下一步        |
| "1700字，包含标点"         | 指定字数（含标点口径）        |
| "开头不够炸"              | 重写开头               |
| "这是对标文案，学一学它的表达：+文案" | S5.5 对标学习（学表达不学立场） |
| "这些例子不对，重新搜"         | 案例立场/事实有问题，重收集     |
| "出封面标题" / "s6"       | 进入封面+标题步骤          |
| "进入s7：+完整修改版"        | 提交改稿让 AI 学习        |
| "全写入，改规则"            | 经验直接升级为正式规则        |
| "你有用我 skill 里面的风格吗"  | 质疑 AI 没按风格写，触发自查   |

## 八、三个高频问题

**Q：AI 直接写完整篇文章，没等我确认？**  
→ 说"谁让你两步一起做的？每次只能做一步"。纠正一句它就会收敛。

**Q：AI 写的文风不对？**  
→ 问它"你有用我 skill 里面的风格吗"，它会自查加载风格系统。v2.1.0 起流程内置了"动手前强制加载风格"检查点，这类问题会越来越少。

**Q：精炼模式它怎么还给我主题选项？**  
→ 旧版 bug，v2.1.0 已修复（精炼模式永远跳过 S3）。还在用旧版就升级。
